# Security Policy

## Supported Versions

This repository currently supports security fixes for the `main` branch only.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Older commits/tags | No |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Preferred reporting path:

1. Use GitHub's private vulnerability reporting flow in this repository
   (`Security` tab -> `Report a vulnerability`), if available.
2. If private reporting is not available, open an issue asking for a private
   contact channel **without sharing exploit details**.

Include as much detail as possible:

- Affected file/module and version/commit
- Steps to reproduce
- Expected impact
- Any proof-of-concept or logs
- Suggested mitigation (if known)

## Response Expectations

- Initial triage response target: within 7 days
- Status updates: at least once every 14 days until resolution
- Fix release timing depends on severity and complexity

## Disclosure

Please allow maintainers time to investigate and release a fix before public
disclosure. After a patch is available, coordinated disclosure is encouraged.
